01
Project Foundation

PROBLEM STATEMENT

In modern recruitment ecosystems, over 75% of qualified resumes are rejected automatically by commercial Applicant Tracking Systems (ATS) prior to human recruiter inspection. Job applicants encounter severe systemic hurdles:

Parsing Glitches

Multi-column layouts, graphics, and unstandardized headers cause automated parsers to scramble candidate experience and contact details.

Opaque Black Boxes

Candidates receive generic rejection emails with zero feedback on keyword density gaps, formatting issues, or missing competencies.

There is a profound lack of accessible, open, educational tools that empower students and job seekers with deterministic ATS readiness diagnostics and actionable, closed-loop career guidance.

02
Project Goals

OBJECTIVE

The primary objective is to engineer a secure, highly scalable, enterprise Java Spring Boot web platform that bridges the gap between candidate qualifications and ATS algorithms:

  • Robust Document Parsing: Extract text reliably from text-based PDFs (Apache PDFBox) and Word documents (Apache POI), while flagging scanned image-only files.
  • Deterministic 6-Factor ATS Scoring: Evaluate keyword density, formatting compliance, section hierarchy, contact completeness, education, and experience.
  • Closed-Loop Skill Gap Bridging: Automatically map identified skill gaps to targeted online courses and verified YouTube video tutorials.
  • Qualitative Generative AI Coaching: Leverage Google Gemini 1.5 Flash with strict prompt-injection guardrails for contextual critique and PDF report generation.
  • Interactive 4-Template Resume Builder: Provide real-time live preview and export to recruiter-ready DOCX and PDF documents.
  • Unified Career Discovery: Aggregate job search queries across 7 leading portals (LinkedIn, Naukri, Indeed, Foundit, etc.) plus live Remotive API integration.
03
Executive Summary

ABSTRACT

In today’s digitized employment marketplace, algorithmic hiring systems reject the majority of job candidates based on superficial document parseability and keyword absence rather than core engineering competency. This project introduces the Smart AI Resume Analyzer (Java Spring Boot Edition) — a full-stack, enterprise-grade software solution built on modern software engineering standards.

The system integrates a hybrid dual-engine architecture: a deterministic rule-based engine that evaluates resumes against an objective 100-point rubric, paired with a generative AI engine powered by Google Gemini for deep qualitative assessment. The application features comprehensive upload security (magic-byte validation, path traversal defense), role-based access control, CSRF protection, CSV formula injection defense, and an interactive 4-style resume builder. The platform has been verified across 24 operational phases with 100% automated test coverage.

Theoretical Foundations

LITERATURE SURVEY

Document Stream Extraction

Apache PDFBox and POI literature underscores that multi-column and graphical resumes create character sequence fragmentation. The proposed pipeline employs linear text stream normalizing to preserve section integrity.

LLMs in Career Diagnostics

Recent NLP research highlights that generative pre-trained transformers provide superior qualitative synthesis when guarded with boundary tokens (`=== BEGIN UNTRUSTED DATA ===`) to prevent instruction overriding.

08
Novel Contributions

INNOVATION & KEY DIFFERENTIATORS

Dual-Engine Synergy

Unlike single-approach tools, Smart AI Resume Analyzer runs rule-based deterministic scoring side-by-side with LLM reasoning. If Gemini API quotas are exhausted, the heuristic engine provides seamless, 100% offline fallback.

Dynamic Skill Gap Bridge

Unmet candidate prerequisites are automatically cross-referenced with course catalogs and verified YouTube tutorials, turning diagnostic feedback into immediate educational action.

100% Null-Safe Resume Builder

Supports 4 distinct resume styles ("Modern", "Professional", "Minimal", "Creative") generating valid binary DOCX and PDF documents without a single "null" string or NPE crash.

Hardened Multi-Format Exports

Administrative telemetry exports to Excel (.xlsx), CSV, and JSON include automated defense against CSV formula execution attacks (`=`, `+`, `-`, `@`, `\t`, `\r`).
