## 3. The Mathematical Scoring Formula

Implemented in [`ResumeAnalyzerService.java` lines 138–146](file:///c:/Users/yasas/OneDrive/Documents/Desktop/D3js%20program/AI%20Smart%20Resume%20Analyzer.java/Smart-Resume-Analyzer-Java/src/main/java/com/smartresume/service/ResumeAnalyzerService.java#L138-L146):

$$\text{ATS Score} = (S_{\text{contact}} \times 0.10) + (S_{\text{summary}} \times 0.10) + (S_{\text{keyword}} \times 0.30) + (S_{\text{exp}} \times 0.20) + (S_{\text{edu}} \times 0.10) + (S_{\text{format}} \times 0.20)$$

## 4. Role of Google Gemini in ATS Scoring

* **Does Gemini Calculate the ATS Score?** **NO.**
* The primary ATS score displayed on the circular dashboard gauge and stored in `resume_analysis.ats_score` is strictly produced by Java's `ResumeAnalyzerService`.
* `AIResumeAnalyzerService` passes the resume text to Google Gemini (`gemini-2.5-flash`), which returns qualitative textual commentary and an estimated score. While Gemini's markdown output mentions an estimated score, the Java backend anchors the mathematical evaluation to its own deterministic formula, using Gemini exclusively for strengths, weaknesses, and course recommendations.

## 5. Worked Numerical Example (Synthetic Candidate Data)

Consider a synthetic candidate resume for a **Software Engineer** role:
- **Contact:** Email found, Phone found, LinkedIn missing. Missing items = 1.
  $$S_{\text{contact}} = 100 - (1 \times 25) = 75.0$$
- **Summary:** Present, 45 words (between 20 and 100 words). Deductions = 0.
  $$S_{\text{summary}} = 100.0$$
- **Keywords:** `JobRolesConfig.getRoleByName("Software Engineer")` requires 10 skills (`Java`, `Spring Boot`, `SQL`, `Git`, `REST APIs`, `Docker`, `Microservices`, `JUnit`, `CI/CD`, `AWS`).
  - Text contains: `Java`, `Spring Boot`, `SQL`, `Git`, `REST APIs`, `JUnit` (6 matched).
  $$S_{\text{keyword}} = \frac{6}{10} \times 100 = 60.0$$
- **Experience:** Has years (`2022-2024`), bullet points (`•`), and action verb (`developed`). Deductions = 0.
  $$S_{\text{exp}} = 100.0$$
- **Education:** Mentions `B.Tech` and `2022`. Deductions = 0.
  $$S_{\text{edu}} = 100.0$$
- **Formatting:** Length = 1,450 chars ($>300$), has uppercase header `EXPERIENCE`. Deductions = 0.
  $$S_{\text{format}} = 100.0$$

### Final Score Compilation:
$$\text{ATS Score} = (75 \times 0.10) + (100 \times 0.10) + (60 \times 0.30) + (100 \times 0.20) + (100 \times 0.10) + (100 \times 0.20)$$
$$\text{ATS Score} = 7.5 + 10.0 + 18.0 + 20.0 + 10.0 + 20.0 = 85.5 \xrightarrow{\text{Math.round}} \mathbf{86.0 / 100}$$

## 6. Fairness, Ethical Evaluation & Quality Deficiencies

### Ethical & Bias Evaluation
* **Fairness:** The algorithm contains **no checks for protected personal attributes** (age, gender, ethnicity, disability, religion). Scoring is purely based on technical keywords, formatting tokens, and contact elements.
* **Non-Rejection Design:** The score is presented to candidates as an informative diagnostic tool with actionable recommendations to help them succeed, not as an automated employer rejection screen.

### Technical Deficiencies Discovered
1. **Substring Collisions:** `lower.contains("java")` triggers on `"javascript"` or `"javadoc"`.
2. **Context Blindness:** A candidate writing *"Spearheaded scalable cloud architecture"* gets 0 points for `"AWS"` or `"Cloud Computing"` because the literal token is absent.
3. **Keyword Stuffing:** Transparent text or lists of raw skills will easily trigger a 100% keyword score without validating actual work experience context.
